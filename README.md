## About This Repository

This repository contains my Object-Oriented Programming (OOP) in Java mini-project, developed as part of the university's OOP Java coursework.

The project implements a *Library Management System* designed to demonstrate the practical application of object-oriented programming principles and software design concepts in Java.

## Project Overview

The Library Management System is designed to manage basic library operations, such as organizing books, maintaining book records, and supporting the borrowing and returning of books.

## Concepts Demonstrated

- *Classes and Objects* — Representing library entities such as books and users.
- *Encapsulation* — Protecting data through access modifiers and controlled access to fields.
- *Inheritance* — Reusing common properties and behaviours where appropriate.
- *Polymorphism* — Allowing objects to implement or override behaviours in different ways.
- *Abstraction* — Simplifying complex operations through abstract classes and interfaces.
- *Exception Handling* — Managing errors and unexpected situations.
- *Collections and Generics* — Storing and managing library records efficiently.
- *File Handling* — Saving and retrieving data, if supported by the implementation.
- *Design Patterns* — Applying suitable design patterns where appropriate.

## How to Run the Project

1. Clone or download this repository.

5. Compile and run the project according to its structure.
